# BUG-0005: Factura repetida se detectaba hasta guardar
- **Funcionalidad:** Entrada de mercancía (XML)  **Prioridad:** Media  **Estado:** Verificado
## 1. Descripción  Al subir otra vez la misma factura, el usuario capturaba fechas y sólo al final veía el error.
## 2. Pasos  Subir el mismo XML dos veces.
## 3. Esperado  Aviso inmediato.   ## 4. Obtenido  Aviso al guardar.
## 5. Prioridad  Media: trabajo perdido.   ## 6. Solución (aplicada)  Se revisa el UUID del CFDI al subirlo: "Esa factura ya la registraste el 18 nov 2026."
