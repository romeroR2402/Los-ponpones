# BUG-0004: Avisos (toasts) encimados
- **Funcionalidad:** global  **Prioridad:** Baja  **Estado:** Verificado
## 1. Descripción  Dos avisos seguidos se dibujaban uno sobre otro e ilegibles.
## 2. Pasos  Subir factura repetida y luego sacar un vencido.
## 3. Esperado  Un aviso legible.   ## 4. Obtenido  Textos encimados.
## 5. Prioridad  Baja.   ## 6. Solución (aplicada)  Al mostrar un aviso se quita el anterior.
